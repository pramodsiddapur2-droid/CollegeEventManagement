# College Event Management System

A full-stack web application for managing college events and student registrations.

## Features

- View college events
- Student event registration
- Admin login
- Admin dashboard
- View registered students
- Search students by name or USN
- Event-wise registration count
- PostgreSQL database
- C++ backend server

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- C++
- cpp-httplib
- REST API

### Database
- PostgreSQL
- Supabase

### Deployment
- Docker
- Render
